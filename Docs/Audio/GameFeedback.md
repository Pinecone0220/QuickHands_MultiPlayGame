# UI와 미니게임 효과음

2026-10-21 갱신. `Tools/Build-GameFeedback.py`에서 합성한 UI/미니게임 효과음13종과 외부 음원 기반 명중음2종이다. 44.1kHz/16bit 모노 PCM이며 `Resources/GameFeedback`에 포함한다.

| 이름 | 재생 시점 |
|---|---|
| UiClick | UI 버튼 활성화. 마우스와 키보드 버튼 활성화 모두 같은 콜백 사용 |
| KeyTap | 퀵핸즈 숫자 입력, 뭐였더라? 방향 입력이 로컬 입력 조건을 통과했을 때 |
| KeyError | 퀵핸즈의 오입력 또는 서버가 확인한 실패 정지 |
| CountdownTick | 파티 시작/퀵핸즈/욕심의 대가의3·2·1마다0.10초 비프음 |
| CountdownStart | 카운트다운 종료 시0.24초의 조금 높은 시작음 |
| ClockLoop | 초읽기 시작 이후 작은 시계 소리. HideAfter부터 0.75초 동안 페이드 후 완전히 정지 |
| ClockConfirm | 초읽기/신호등 정지가 서버에서 확인됐을 때 |
| SignalWait | 신호등 대기 및 가짜 신호에서 대기로 복귀 |
| SignalFake | 가짜 신호 |
| SignalGo | 실제 출발 신호. UI와 같은 SignalAt/ServerTime 기준으로 재생 |
| GreedLoop | 욕심의 대가 점수 증가 중 작은 반복음. 정지 입력 시 멈춤 |
| GreedConfirm | 욕심의 대가 확정 성공을 서버가 확인했을 때 |
| GreedBurst | 실제 폭발이 공개된 시점. 이미 점수를 확정한 사람도 한 번 듣는다 |
| HitConfirm | 서버가 실제 피해를 확인한 사격자에게만 짧은 충격·금속성 타격음. 소드오프/테이저 포함 |
| HitHead | 리볼버 머리 명중은 일반음 대신 더 높고 선명한 타격음 |

`DuelGameAudio`는 기존 서버 상태를 읽어 로컬로 재생하며 게임 규칙/시각/정답/점수를 수정하지 않는다. 라운드·미니게임 변경에 재생 플래그를 초기화하고 반복된 스냅샷이나 확인 응답으로 효과음을 중복 재생하지 않는다. 오래된 초기 신호·폭발은 재생하지 않고, 방을 떠나면 반복음을 정지한다.

뭐였더라?의 입력음은 정답/오답이나 방향에 따라 달라지지 않는다. 비공개 판정이 소리로 드러나지 않게 한다. 초읽기의 타이머 수치와 정지 판정은 기존 식을 유지하며 소리만 페이드한다. 신호등의 기존 룰렛 소리 재활용은 제거해 중복을 피한다.

미리듣기 묶음: `Docs/Previews/GameFeedback-Preview.wav`.

## 검증
Unity 실제 런타임에서 47개 검사를 통과했다. 음원 디코딩, 입력/버튼 활성화, 초읽기 숨김 페이드/무음과 시각 유지, 정지 거절/확인 응답, 신호별 중복 방지와 버퍼 시각, 욕심 점수/확정/폭발, 과거 초기 상태, 종료 정리 및 실제 AI 퀵핸즈의 리볼버 ADS 가늠쇠 정렬을 확인했다.

## 명중 확인음 (2026-10-21)
사용자 요청에 따라 앞서 합성한 두 타격음을 교체했다. 일반 명중은 DrAbcOfficial/HitSound가 Overwatch hit로 배포한 음원을 볼륨 조절·PCM 변환한0.0377초 소리다. 리볼버 머리 명중은 같은 소리를1.35배 높여 만든0.0279초 소리이며 별도 추출한 오버워치 헤드샷 원음은 아니다. 출처/커밋/해시는 Sources.md에 기록한다. 일반/머리 순서의 미리듣기는 `Docs/Previews/HitFeedback-Preview.wav`다.

기존 서버 피해 확인 경로의 사격자 전용 ReportHitRpc에 서버가 결정한 headshot bool을 함께 보낸다. 사운드가 NetworkVariable의 도착 순서에 따라 달라지지 않으며, 같은 Round/Life/shot의 히트마커 중복/구생명 검사 뒤에 한 번만 재생한다. 피해 없는 빗나감·병/잔 파손과 타인 명중은 무음이다. 소드오프는 다중 피해/산탄 수와 무관하게 한 번, 소드오프/테이저의 머리 접촉도 일반음이다. 별도 비공간 AudioSource(우선순위60/음량0.8)를 사용한다. RPC 형식 변경으로 프로토콜44다.

## 시작 카운트다운 (2026-10-21)
외부 샘플 없이 합성한660Hz 비프와990/1320Hz 시작음을 사용한다. UI와 같은 StageStartedAt/Clock.StartedAt/ServerTime으로 계산한다. 같은 숫자는 반복하지 않고 시각이 잠깐 뒤로 가도 이미 지난 숫자를 다시 재생하지 않는다. 지연으로 건너뛴 숫자는 몰아서 재생하지 않으며 시작음은 종료 시각에서0.35초 이내에만 재생한다. 취소/이탈 시 초기화하고 파티 시작→룰렛의 iteration 변경도 시작음을 누락시키지 않는다. 새 RPC/시간 규칙 변경 없이 프로토콜44 유지. 미리듣기: `Docs/Previews/Countdown-Preview.wav`.

Unity 편집기에서 두 음원의 임포트/PCM 디코딩과 실제 프레임 진행을 확인했다. 파티 시작·퀵핸즈·욕심의 대가 각각 비프3회/시작1회, 총 비프9회/시작3회였다. 로그: `%TEMP%/RouletteQA-bb1739d9/countdown-audio-preview.log`. 네트워크/게임 판정 코드는 변경하지 않았다.

# 마지막 잔 / Last Call

2026-10-26: 현재 게임 배경음악은 사용자 지정 `Local Forecast - Elevator`로 교체했다. 이 문서는 이전 자체 제작 곡의 기록이다. 최신 적용/출처는 `LocalForecastElevator.md`를 참고한다.

2026-10-20. 어두운 바와 원형 테이블의 분위기에 맞춘 오리지널 합성 배경음악.

- 길이: 약 1분 53초, 68 BPM, 4/4박자, 32마디.
- 편성: 부드러운 전자피아노 코드와 짧은 선율, 낮은 플럭 베이스, 작은 브러시 드럼.
- 코드: Dm9 → G13 → Cmaj9 → Fmaj9 → Bm7♭5 → E7♭9 → Am9 → A7♭9.
- 8마디 진행을 네 가지 선율로 전개한다. 보컬과 외부 음악 샘플을 사용하지 않았다.
- 음표 잔향과 실내 반사음을 파일 시작 부분으로 이어 붙여 반복한다. 전체 WAV에는 매 반복마다 생기는 페이드아웃을 넣지 않았다.
- `Tools/Build-BarMusic.py`로 동일 곡을 재생성할 수 있다. Python과 numpy가 필요하다.

## 게임 적용

`DuelBackgroundMusic`이 `Resources/Music/LastCall`을 2D 반복 재생한다. 메인 화면/로비의 AudioSource 볼륨은 0.28, 경기 중에는 0.16이며 부드럽게 바뀐다. 방 입장·퇴장·미니게임 전환마다 음악을 재시작하지 않는다. 총기 소리보다 낮은 재생 우선순위를 사용한다. 음악은 각 기기에서 로컬로 재생하며 네트워크 규칙을 바꾸지 않는다.

Unity에서는 스테레오 Vorbis 스트리밍으로 가져와 전체 곡을 PCM 메모리에 상주시킬 필요가 없도록 했다. 원본 WAV는 44.1kHz/16bit 스테레오이고 렌더 수치는 `LastCall.json`에 기록한다.

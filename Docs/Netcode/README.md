사용자가 전달한 링크는 표시 주소가 NGO 2.13이고 실제 링크는 Unity 2020.3의 다른 NetCode 문서였다. 설치 패키지와 일치하는 [NGO 2.13 공식 매뉴얼](https://docs.unity3d.com/Packages/com.unity.netcode.gameobjects@2.13/manual/index.html)을 기준으로 삼는다.

## 먼저 적용할 규칙

1. 클라이언트-서버에서 중요한 게임 결과는 서버가 결정한다. 소유권과 서버 권한은 다르다.
2. 지속 상태는 `NetworkVariable`/`NetworkList`, 순간 요청·이벤트는 `[Rpc]`로 표현한다.
3. NGO 2.13.3의 RPC 기본 호출 권한은 `Everyone`이다. `SendTo.Server`만으로 소유자 전용이 되지 않는다. `InvokePermission`과 서버의 게임 규칙 검증을 함께 사용한다.
4. `OnNetworkSpawn`에서 이벤트를 구독하고 현재 상태도 즉시 적용한다. `OnNetworkDespawn`에서 구독을 해제한다.
5. `Update`는 스폰 전에도 호출될 수 있다. 네트워크 작업에는 `IsSpawned`와 적절한 권한 검사가 필요하다.
6. `Instantiate`만으로 원격 생성되지 않는다. 등록된 네트워크 프리팹과 권한 있는 `Spawn`/`Despawn`이 필요하다.
7. 하나의 Transform에 여러 동기화 방식이 동시에 위치를 쓰지 않도록 한다.
8. 공유 씬은 NGO 씬 관리와 완료 이벤트를 사용한다. Unity의 `sceneLoaded`만으로 네트워크 준비 완료를 판단하지 않는다.
9. 호스트만 테스트하지 않는다. 원격 클라이언트, 전용 서버, 늦은 참가, 끊김·재접속도 변경 범위에 맞게 확인한다.
10. API가 애매하면 아래 상세 가이드와 설치 패키지를 확인한다. 과거 버전 기억으로 단정하지 않는다.

이 자료는 주요 개발 주제를 분석한 실무 가이드이며 전체 API 레퍼런스를 번역한 문서는 아니다. 예제의 런타임 검증 여부와 아직 확인하지 않은 사항은 상세 가이드에 구분했다.


현재 무기0은 데린저 대신6연발 리볼버(DuelWeapon.Revolver)다. 준비5행동×6자리 후 한 발마다3자리, 최대6발 장전한다. 퀵핸즈에서 우클릭은 빈 총도 조준할 수 있으며 부분 장전 중 조준 사격도 가능하다. 남은 탄은 숫자 입력 없이 계속 발사하고, 빈 총의 발사는 서버가 거절한다. 탄 수 텍스트는 없으며 실린더/장전 게이트를 표시한다. 관련 최신 설계는 상세 가이드19.30절.

사격 후 재장전은 리볼버 탄피 빼기(실탄 보존), 소드오프 배럴 열기(자동 탄피 배출)부터 반복한다. 상세 가이드19.39절 참조.

총기 효과음은 확정 상태를 로컬3D로 재생한다. 방장은 F11 개발자 모드에서만 설정하며 끄면 네 설정을 기본값으로 복원한다. 술병/잔/1회 음주 활동과 실제 탄환 파손은 서버 상태이며19.40절 참조.

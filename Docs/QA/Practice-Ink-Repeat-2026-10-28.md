# 로비 먹물팩 반복 투척

로비 연습에서는 투척 후에도 먹물팩 장착 상태를 유지한다. 이전 비행과 투척 동작이 끝나면 다시 발사하며, 이전 비행 중 중복 요청은 거절한다. 총이나 다른 아이템으로 변경할 수 있고 본 경기의 소모 규칙은 유지한다. 프로토콜63.

- 서버 모델: `Tools/Test-PracticeItems.ps1` 31개 통과. 반복 투척, 중복·오래된 요청 거절, 비행 중 총 전환, 준비 취소와 실제 경기 아이템 초기화 확인.
- 호스트·원격 참가자·관전자 3개 실행 파일: 34개 통과. 반복 투척 후 장착과 아이템 강조, 다른 화면에서 손에 든 먹물팩 표시, 총 전환 및 먹물 효과 동기화 확인.
- 기존 먹물 조준 480개, AI 장비 171개, 패딩 46개, 총알 아이템 44개 검사 통과. Windows Development 빌드 성공.

# 저격소총 손·시점 추적 검증 — 2026-10-27

Unity6000.3.18f1 / NGO2.13.3 / 프로토콜57 유지. 로컬 표현 변경이며 서버 탄도/피해/장전 입력/시선 RPC는 변경하지 않았다.

변경:

- 오른손은 손잡이·방아쇠·레버, 왼손은 앞받침을 감싸는 전용 로우폴리 손가락/손바닥 메시를 사용한다. 탄 장전은 엄지·검지로 집는 손으로 전환한다.
- 레버 갱신 후 오른손을 현재 레버에 배치하고 왼손은 앞부분을 받친다. 준비 동작별로 총을 기울여 약실과 레버를 보여준다.
- 카메라 회전은 즉시 따라가고 자세 전환만 시야 기준 국소 좌표에서 보간한다. 받침 손은 총에 직접 연결하고 팔꿈치도 현재 시선으로 계산한다. 양팔 길이는 유지한다.
- 스코프에서는 해당 화면의 무기·양팔·손·패딩 소매만 가리고 해제 시 복원한다. 몸통 표시와 타인 화면의 손/총 표시는 유지한다.

검증:

- Windows Development 빌드 성공.
- BasHandsRuntimeQA 실제 별도 실행 호스트67개/원격3개 통과.
- 급격한 좌우/상하4방향 전환 뒤 한 프레임 내 총 회전·손목/하완 끝점 일치, 고정 팔 길이 확인.
- 스코프의 손/팔 가림·몸통 유지·해제 복원, 원격 화면의 스코프 사용자 손/총 표시 확인.
- 집기/레버 열기/탄 장전/레버 닫기의 실제 숫자 입력·손 위치·각도와 첫 발 사격/후속 레버 조작/탄피 배출 확인.
- 일반 사격/스코프/아래쪽 스코프/각 준비 행동 캡처를 육안 확인했다.

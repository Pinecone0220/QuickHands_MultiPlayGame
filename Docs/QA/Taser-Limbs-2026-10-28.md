# 피격 반응과 테이저 팔다리 판정

- 피격 반응을 짧은 몸통 반동과 작은 머리 움직임으로 조정했다. 시선, 감전, 손의 무기 고정과 쓰러지는 연출은 유지한다.
- 테이저 히트스캔에 여유 있는 양팔·손·다리·발 영역과 소폭 넓힌 몸통·머리를 적용했다. 팔은 몸통으로 기록하며 테이저 피해는 어느 부위든5다. 서버 판정과 클라이언트 전기선이 동일한 경로를 쓴다. 일반 총기, 테이블/의자/벽·소품 가림, 패딩 면역과 5.5m 사거리는 유지한다. 프로토콜64.
- `Tools/Test-TaserLimb.ps1`: 138개 통과. 여섯 좌석 양쪽 팔·손·다리, 여유 범위 밖 빗나감, 의자 가림, 인접 좌석 팔 적중과 일반 총기 판정 유지.
- 기존 테이저 히트스캔82개, 로비 연습31개, AI 장비171개, 먹물 조준480개, 전투/승자58개 검사 통과.
- Windows Development 빌드와 호스트12개·원격 클라이언트9개 검사 통과. 원격 참가자의 팔 사격으로 피해5·감전과 양쪽 화면의 전기선, 감전 종료와 실제 처치 처리를 확인했다. 실제 별도 PC의 LAN 환경은 검증 범위에 포함하지 않는다.

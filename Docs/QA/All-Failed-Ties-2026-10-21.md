# 전원 동점·전원 실패 사격자 검증

Unity 6000.3.18f1 / NGO 2.13.3 / 프로토콜43 유지.

기존에는 신호등 전원 실패/욕심의 대가 전원 폭발의 주사위 순위가 확정되어도 Failure 조건 때문에 First=-1이 되었다. 이제 확정 순위1등을 사격자로 지정한다. 초읽기 시간 초과 참가자는 기존대로 후보에서 제외한다.

- 격리 Unity 에디터 규칙 검사110개 통과. 기존 주사위/미니게임52개와 새 회귀58개를 포함한다.
- 새 검사는2명/6명에서 신호등 전원 성급 입력·전원 미입력·실패 종류 혼합, 욕심의 대가 전원 폭발·동일0점, 초읽기 동일 정상 기록을 다룬다. 주사위→결과3초→아이템5초→사격 전환을 확인했다.
- Director에서 전원 실패/폭발 후 살아 있는 사격자의 조준 단계·한 발 지급을 확인했다. 초읽기 전원 시간 초과는 주사위 대상0/사격자 없음/각 목숨1 차감/사격 생략/다음 게임 복귀를 확인했다.
- Windows 개발 빌드 성공. 독립 실행본3개에서 호스트23·원격23·대기자20, 총66개 검사 통과. 전원 폭발의 실제 SPACE→소유자 RPC→주사위 순위·사격자·한 발 지급·목숨 보존을 모든 화면에서 확인했다. 기존 퀵핸즈 동시 사망/목숨0 주사위 참여도 통과했다.

합계176개. 전용 서버/실제 인터넷 지연·손실 검사는 이번 범위에 포함하지 않았다. 제작 소스와 격리 QA 소스의 관련 파일 해시가 일치한다.

재현 도구: `Tools/UnityQA/DiceRuntimeQA.cs`. 격리 프로젝트에서 모델은 `--dice-qa model --dice-dir <결과 폴더>`, 실행본은 각자 `--dice-qa host/client/observer --dice-all-failed --dice-dir <공유 결과 폴더>`를 사용한다. 각 실행에는 비어 있는 새 결과 폴더를 사용한다. 테스트 전용 기록/상태 조작은 제품의 관리 API/RPC로 노출하지 않는다.

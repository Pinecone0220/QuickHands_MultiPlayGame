# 마우스 휠 장비 전환

- 로비 연습은 총기·선택된 테이저·먹물팩을 순환한다. 대난투는 총기와 선택한 장비를 전환하고, 다른 미니게임의 사격 중에는 현재 사격 장비와 먹물팩을 전환한다. 위/아래 휠은 반대 방향이다.
- 채팅과 Alt UI 조작, 감전 중에는 전환하지 않는다. 사용할 수 없거나 재사용 대기 중인 아이템은 건너뛰며, 앰플·총알·노루페이스는 휠을 돌려도 소비되지 않는다. 기존 소유자 RPC와 서버 검증을 사용한다. 프로토콜64와 패치노트는 유지한다.
- `Tools/Test-EquipmentWheel.ps1`: 21개 통과. 양방향 순환, 선택 아이템, 쿨타임과 무한 아이템, 투척 비행, 감전과 단계별 제한을 확인했다.
- Windows Development 빌드와 실제 입력 시스템 휠 이벤트로 로비 호스트8개·원격 관찰자1개, 대난투/일반 사격 호스트12개·원격 참가자14개 검사 통과. 채팅·Alt 중 휠이 장비를 변경하지 않고, 대난투 장전 진행이 유지되며 일반 사격에서는 테이저와 먹물팩 사이를 전환하는 것을 확인했다.
- 기존 로비 아이템31개·테이저82개·AI 장비171개 서버 검사 통과. 별도 PC 간 LAN 검증은 포함하지 않는다.

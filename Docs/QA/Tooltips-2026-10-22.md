# 무기·아이템·체력 위 무기 툴팁

2026-10-22 / 로컬 UI 수정 / 프로토콜49 유지.

준비 패널(최종 결과에서 재사용)의 무기/시작 아이템 버튼과 체력 위 선택 무기 패널에 이름과 핵심 효과2줄 이내의 툴팁을 추가했다. Alt 홀드 중0.18초 호버 뒤 표시하고 포인터 이탈/Alt 해제/방 이탈 때 숨긴다. 비활성 버튼도 설명을 읽을 수 있다. HUD의 SelectedWeapon 변경을 반영하며 화면 밖으로 나가지 않게 위치를 보정한다. 툴팁 전체는 PickingMode.Ignore여서 선택/채팅 클릭을 가로채지 않는다.

`Tools/UnityQA/TooltipPreviewQA.cs`에서 가상 InputSystem 마우스를 실제 패널 좌표로 움직여 생산 코드의 Panel.Pick 경로를 구동했다. Unity 컴파일/그래픽 실행32개를 통과했다. 무기3종·아이템2종 문구, 비활성 선택 읽기, 선택 변경 후 HUD 문구, 우측/아래 경계, 준비 상태 불변, 포인터 이탈과 Alt 해제 시 숨김을 확인했다. 최종 결과의 같은 버튼에는 동일한 바인딩이 유지된다. 이번 변경은 네트워크/게임 규칙을 수정하지 않아 별도 멀티프로세스 검사는 반복하지 않았다.

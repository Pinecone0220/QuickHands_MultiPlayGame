## 확인한 원인과 변경

이전 코드 참가는 방 목록과 같은 UDP 브로드캐스트 검색을 재사용했다. 따라서 목록이 보이지 않는 사용자에게 코드를 알려 줘도 검색 차단을 우회하지 못했다. 코드 조회2초와 어댑터별 응답 주소 덮어쓰기도 보완했다. 실제 사용자 실행 파일의 프로토콜은55였다. 외부 참가자의 방화벽/공유기 차단 여부는 확인하지 못했으므로 이를 확정 원인으로 단정하지 않는다.

- 방 목록을 기본 참가 버튼으로 유지. 활성 LAN NIC별 소켓과 제한 유니캐스트 탐색을 추가하고 브로드캐스트를 병행한다.
- 코드 조회8초, 광고 만료12초. 응답 주소 안정화 및 구버전 광고(코드 필드가 없는 프로토콜54 포함) 별도 진단.
- 목록 검색이 막히면 방장의 초대 코드 복사→목록 창의 직접 참가. 초대 코드는 LAN endpoint/세션 GUID만 공유하며 비밀번호/proof를 포함하지 않는다. 기존 NGO 승인/정원/진행 상태 검증을 유지한다.
- Player.log에 검색 시작/어댑터 수/발견 endpoint/다른 프로토콜/연결 시도를 기록한다. 방화벽이나 네트워크 설정은 변경하지 않았다.

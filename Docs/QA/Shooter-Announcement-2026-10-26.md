# 사격자 안내 연출 확인

2026-10-26 / Unity6000.3.18f1 / 프로토콜52 유지. 표시 변경만이며 사격 권한/미니게임/아이템/결과 시간은 유지한다.

최종 사격자 결정 때 중앙에 `닉네임가 사격을 준비합니다!`를 띄우고0.8초 뒤0.75초 동안 상단으로 이동하며65% 크기로 축소한다. 도착하면 `닉네임가 사격합니다!`로 바꾸며 사격 종료까지 유지한다. 목숨 차감 숫자 연출 중에는 중앙 안내를 겹치지 않는다. 기존 하단 역할 안내는 유지한다.

격리 Unity 에디터에서 실제 호스트를 실행하고 서버 상태로 결과→아이템→사격→종료를 진행했다.1200×800 캡처에서 중앙 중심(600,400), 최종 상단24px/축소0.65와 정확한 문구를 확인했다. 단계 전환 중 위치가 초기화되지 않았으며 뒤늦게 Shooting을 받은 경우도 중앙 재생 없이 상단으로 표시됐다. Returning과 퇴장에서는 display=None이다. C# 컴파일 오류는 없었고 기존 Unity Search 초기화 예외와 구분했다. 별도 Windows 재빌드/원격 PC 검증은 추가하지 않았다.

# BAS 레버액션 정정 / 첫 탄피 배출

참조 이미지에 맞춰 은색 리시버·어두운 목재 앞손잡이/개머리판·총열 아래 튜브·아래쪽 레버 고리로 변경했다. 외부 볼트 손잡이를 제거했다. 오른손이 레버를 내리고 왼손은 총 앞부분을 받치며, 장전 때에는 배출구에 한 발을 삽입한다. UI 및 킬로그/HUD 실루엣도 레버액션에 맞춘다. 입력4자리/최초4행동·후속3행동, 스코프, 피해와 목숨 규칙, 지정 효과음은 유지한다.

사격 후 서버의 레버 열기 완료/SpentMask 제거를 관찰하면 빈 탄피를 별도로 띄운다. 탄피는 세계 좌표에서 회전/포물선으로 움직이고0.85초 후 사라진다. 좌석당 하나를 재사용한다. 렌더 전용이며 물리 콜라이더·피해·RPC는 추가하지 않았다. 새 경기/생명/연습 세션·최초 스냅샷·무기 해제에는 초기화하고 동일 스냅샷은 배출을 반복하지 않는다. 프로토콜46 유지.

검증:

- 실제 Unity 편집기 컴파일/그래픽 실행38개 통과. 첫 빈 총 준비→실제 첫 사격→SpentMask1→레버 열기 완료→별도 탄피 발사/세계 이동/중복 방지/소멸을 확인했다. 스코프/음원 로드/장전도 확인했다.
- 기존 BAS 서버 규칙284개 회귀 통과. 네트워크 형식/서버 행동/피해는 변경하지 않아 이번에는 다중 프로세스 검사를 재실행하지 않았다.

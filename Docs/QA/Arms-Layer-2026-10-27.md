# 1인칭 팔·표시 순서 수정

- Unity 6000.3.18f1 / NGO 2.13.3 / Windows Development 빌드 성공. 로컬 표현 수정으로 프로토콜60 유지.
- 월드 up 기준의 최소 회전 대신 시선 기준의 회전축으로 팔의 roll을 정한다. 1인칭은 하완0.50m·상완0.40m 고정 길이로 연결하고 상완을 표시한다. 타인 모델의 기존 길이·IK·서버 판정은 유지한다.
- 자기 총/손/팔만30번 렌더 레이어로 분리한다. 투명 RGBA 타깃에 UI 갱신 전 렌더하고 공간 이름표 → 총/팔 → 버튼·입력·결과창 순서로 합성한다. 주사위31번 레이어와 분리하며 클릭은 통과한다.
- 해상도 변경 시 타깃을 재생성한다. 준비 취소/퇴장 시 표시를 비우고 모델 레이어를 복원한다. 스코프에서 자기 팔 숨김·타인에게 무기/손 표시를 유지한다.

## 검증

`Tools/UnityQA/BasHandsRuntimeQA.cs`: 실제 호스트110개·원격 클라이언트3개 검사 통과.

- 여러 좌우/상하 각도로 즉시 회전해도 손목 접합과 시선 기준 roll 유지.
- 하완/상완 접합과 고정 길이, 스코프 전환/아래 보기, 첫 준비·장전·레버 재장전·탄피 배출.
- 리볼버/소드오프 전환과 준비 취소, 렌더 타깃 크기 변경, 퇴장 시 가시성·레이어 복원.
- 투명 타깃에서 불투명 모델82,294픽셀·투명 배경877,706픽셀(1200×800), UI 순서·클릭 통과 확인.
- 원격 플레이어에게 저격소총/받침 손/팔이 계속 보이는지 확인.

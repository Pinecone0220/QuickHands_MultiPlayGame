# 1인칭 자기 몸 표시 검증

2026-10-26 / Unity6000.3.18f1 / NGO2.13.3 / 프로토콜54 유지.

기존 자기 모델 전체 숨김을 머리/목만 숨기는 방식으로 바꿨다. 자기 몸통·팔다리·손과 착용 패딩은1인칭에서도 보인다. 머리 장식도 숨기며 타인에게는 전체 모델을 표시한다. 목을 HeadRenderers 마지막에 추가해 카메라 바로 아래의 목 단면이 화면을 덮는 현상을 막고 기존 머리/이름표 기준을 유지했다. 카메라 좌석 눈 좌표·시선·FOV·애니메이션·서버 피격 크기는 변경하지 않았다.

병/잔/따르는 줄도 자기 손과 함께 표시한다. 먹물팩은 실제 캐릭터 손 위치와 그립 회전을 사용하고 별도 로컬 손 프록시는 제거해 이중 손을 방지했다. 투척 원점·포물선·실제 피격/네트워크 필드에는 변화가 없다. 총기/조준경의 기존 뷰모델은 유지한다.

- Windows 개발 빌드 통과: 격리 프로젝트 `C:/Users/PC/AppData/Local/Temp/RouletteQA-bb1739d9`, `body-view-final-build.log`.
- 실제 호스트34개·원격 클라이언트34개 통과(`body-view-final-{host,client}.log`, `Body-View-Final`). 로비/패딩 착용/사격 중 본인 머리·목만 숨김과 몸 표시, 타인 머리 표시, 좌석 눈 카메라 고정, 자기 이름표 숨김, 패딩 실제 표시, 자기 술 소품 표시, 최종3인칭 모델 복원을 확인했다.
- 실제 카메라1200×800 렌더를 직접 확인했다. 아래를 본 일반 상의/노루페이스와 원격 소유자의 몸, 정면 정조준 시야를 저장했다: `Docs/Previews/Body-First-Person-{Lobby,Noru,Aim,Client}.png`.
- 기존 Avatar/Loadout/Reload/Tabletop QA의 전체 자기 모델 숨김 기대값을 새 머리/목 마스크 기준으로 갱신했다. 해당 전체 레거시 스위트를 이번에 재실행한 것은 아니며 실제 실행 검증은 전용 `Tools/UnityQA/BodyViewRuntimeQA.cs`다.

중간 렌더 검사에서 목 단면 가림을 발견해 숨김 목록에 포함했다. QA가 최종 카메라 높이를 영구 사망 관전용6m로 고정해 검사하던 조건도 실제 최종 결과의 별도 고정 위치/FOV 검사로 바로잡았다. 최종 검사는 모두 통과했다. 동일 PC의 별도 네트워크 실행 파일이며 별도PC/LAN 지연·손실·전용 서버와 실제 먹물팩 투척 재검사는 미포함이다.

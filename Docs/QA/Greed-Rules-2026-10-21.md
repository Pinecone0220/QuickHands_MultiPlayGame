# 욕심의 대가 가속·폭발·사격권 검증

Unity6000.3.18f1 / NGO2.13.3 / 프로토콜43 유지. Windows 개발 빌드 성공.

새 규칙90개, 기존 주사위/기억/전원 실패/초읽기 시간 초과 회귀133개, 독립 호스트26·원격26·세 번째 참가자23개, 총298개 검사를 통과했다.

- 점수는 시작 전0, 10초5,555점·15초18,750점·20초44,444점·30초150,000점이며 이후 더 올라가지 않는다. 매초 증가량이 커지는지 확인했다.
- 숨은 기준값50/1,000/150,000과 확률 표본의 경계를 검사했다. 실제 폭발 점수는50 이상·기준값 이하, 실제 진행 시간은30초 이하다. 기준값에서는 확률1, 50점 미만은0이며 중간 확률에서도 기준값 전에 폭발한다.
- 점수 확정의 시작/폭발 직전·정확한 폭발 시각/도착 여유 경계를 확인했다. 비공개 기준값/미래 폭발 시각이 달라도 폭발 전 공개 상태는 같으며, 개인 정지/점수도 결과 전까지 공개하지 않는다.
- 최고 점수 그룹만 주사위를 굴린다. 최고 점수가 한 명이면 하위권 무승부는 생략한다. 전원 폭발에서도 최고 눈이 한 명이면 하위 눈의 재굴림 없이 그 한 명이 사격자가 된다. 우승 후보 이탈 시 새 참가자 마스크/권한도 확인했다.
- 실제3개 실행본에서 자연 발생한 전원 폭발→소유자SPACE/RPC 주사위→동일한 사격자/한 발 지급→목숨 보존을 확인했다. 이후 퀵핸즈의 기존 무승부 처리도 통과했다.
- AI3난이도는 비공개 기준값을 바꿔도 같은 입력 표본에 같은 확정 일정을 선택한다. 화면 소스에 위험도 표시가 남지 않았고 점수만 천 단위 구분으로 표시한다.

점수/확률 판정은 서버에서 하고 폭발 시각은 누적확률의 역추첨으로 한 번 결정한다. 프레임/틱마다 확률을 재추첨하지 않는다. 관련 제작 소스와 격리 QA 소스 해시가 일치한다. 전용 서버/실제 인터넷 지연·손실 실기동은 이번 범위에 포함하지 않았다.

재현 도구: 격리 QA 프로젝트의 Tools/UnityQA/GreedRulesRuntimeQA.cs에 `--greed-rules-qa <새 결과 폴더>`. 주사위 회귀는 DiceRuntimeQA.cs의 `--dice-qa model --dice-dir <새 폴더>`, 원격은 각 실행본에 `--dice-qa host/client/observer --dice-all-failed --dice-dir <공유 새 폴더>`를 사용한다. QA 상태 조작은 제품RPC에 추가하지 않았다.

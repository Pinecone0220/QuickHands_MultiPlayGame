# 봇 총기·아이템 다양화 검증

2026-10-26 / Unity6000.3.18f1 / NGO2.13.3 / 프로토콜54 유지.

로비부터 봇 무기를 리볼버/소드오프/저격소총으로 순환 배정하고 서로 다른 아이템2개 조합을 배정한다. 최종 재경기에만 무기와 두 아이템 조합을 바꾸며 미니게임 사이의 장비/소모품은 유지한다. 봇1명도 재경기를 거치면 세 무기와 다섯 아이템을 모두 고른다. 사람과 PvP 선택은 건드리지 않는다.

회복은 체력50 이하에서 우선하며, 총알은 사격자만, 패딩은 사용 가능한 적 테이저가 있을 때 사용한다. 이미 활성화돼 쿨다운이 시작된 적 테이저도 현재 턴의 위협으로 계산한다. 대난투는 한 아이템 제한 아래 후보 순서를 순환한다. 테이저/먹물 사용 뒤 원래 총기로 복귀하며 무한 아이템에서도 장비 반복 사용 때문에 총기 진행이 막히지 않는다. 일반 턴 먹물은 준비 중 꺼내 두고 실제 포물선으로 투척한다.

저격소총은 머리를 겨냥하며 소드오프는 정조준하지 않는다. 공개된 흔들림·총구 위치를 고려한 AI 조준에도 기존 난이도별 오차를 유지한다. 입력 속도/오입력 확률, 실제 무기별 숫자 입력·장전·Version/탄약/피격 검증을 생략하지 않는다. 잘못된 발사는 재시도한다. 추가 선택·사용 기록은 서버 내부이며 기존 스냅샷 필드를 재사용한다.

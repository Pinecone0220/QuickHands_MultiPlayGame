# 장비 전환 중 장전 입력창

- 로비 연습과 대난투에서 먹물팩이나 테이저를 든 동안 숫자 입력창을 숨긴다. 먹물 투척 동작이 끝나고 총으로 돌아오면 기존 입력 진행 상태로 다시 표시한다.
- 로컬 UI 표시만 수정했다. 서버 동작·패치노트·프로토콜64는 유지한다.
- Windows Development 빌드 성공. 로비에서 실제 저격소총 발사·레버 숫자 입력 후 장비 전환과 복귀를 호스트23개·원격 참가자11개·관전자5개 검사로 확인했다.
- 대난투 원격 참가자의 먹물팩 전환 후 입력창 숨김·복귀·진행 상태 보존을 포함해 호스트12개·원격 참가자12개 검사가 통과했다.

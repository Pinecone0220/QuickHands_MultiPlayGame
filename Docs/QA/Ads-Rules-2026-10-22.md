# 소드오프 정조준 제거·정조준 전용 흔들림 검증

2026-10-22 / Unity6000.3.18f1 / NGO2.13.3 / Transport2.7.3 / 프로토콜49.

소드오프의 ADS를 로컬 입력과 서버 Look/Fire/준비 연습에서 제거했다. ADS=true 요청도 일반 사격으로 정규화한다. 정조준 줌/검은 ADS 가장자리는 없으며37개 산탄·반각6도·20m로 통일했다. 기존 지향12도·6m/ADS0도·20m 구분을 대체한다. 실제 피격/가림/직격75·번호 이웃25 규칙은 유지한다. 정조준 상태가 계속 false여도 AI가 목표 확보 후 사격하고 재장전 후 다시 겨냥하도록 수정했다.

공통 Sway는 지향사격과 ADS 미지원 무기에서0을 반환한다. 카메라·총기·서버 발사 방향이 같은 함수를 쓰며 리볼버/BAS의 기존 정조준 진폭과 지향 탄퍼짐은 유지한다. 감전/피격/반동과 오입력 UI 진동은 별도 효과로 유지한다. 서버 탄도 의미가 달라 프로토콜49를 사용하며 필드/RPC/권한/잔탄·Version·생존·시간 검증은 유지한다.

Windows 빌드 성공 후 모델63개, 실제 호스트3개/원격 클라이언트7개를 통과했다. 모델 내부에서 기존 DuelHighlightsChecks의41개 검사도 실행했다.

- 6개 좌석×4개 무기의 지향 흔들림0/ADS 지원 여부별 흔들림, 리볼버/BAS의 기존 퍼짐과 ADS 정확도를 확인했다.
- 소드오프는 요청 ADS 값에 관계없이6도/20m/같은 발사 원점이며 새 시드가 실제 산탄 배치를 바꾼다.
- 실제 서버 투사체가 이전6m 범위를 넘어 반대편 좌석까지 도달하고, 범위 밖을 겨냥하면 빗나가는 것을 확인했다.
- 본 경기 서버 Look/Fire에서 소드오프 ADS=true 정규화, 무흔들림 발사 방향, 기존 탄 소모/배럴 열기 재장전을 확인했다.
- AI 소드오프가 ADS 상태를 기다리며 멈추지 않고 두 번 이상 사격했다.
- 원격 클라이언트가 우클릭을 유지해도 Ads=false/FOV75/무흔들림이다. 준비 연습과 본 경기에서 ADS=true를 직접 제출해도 소유자/서버 모두 FiredAds=false·FiredSpread6과 정상 탄 소모를 확인했다.
- 박제 문구는 이번에 변경하지 않았다. 기존100 이상 무킬 피해·희귀 사실 우선순위·일반 기록 제외·문장형 대체·서버 동결/직렬화41개 검사를 통과했다. 최종 결과의 Results.Highlight 경로는 유지하며 미니게임 결과에는 별도 박제 표시가 없다.

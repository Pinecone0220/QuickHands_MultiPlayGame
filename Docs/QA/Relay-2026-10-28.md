# Relay 접속 검증

- Unity 6000.3.18f1, NGO 2.13.3, Unity Transport 2.7.3, Multiplayer Services 1.2.1.
- PvP 방장은 Relay DTLS 할당을 생성하고 참가 코드를 공유한다. 참가자는 코드로 할당에 연결한다. 게임 규칙과 승인·정원 검사는 방장의 NGO 서버가 처리한다.
- Windows 빌드의 별도 두 프로세스가 실제 Unity 서비스에 접속해 호스트 생성, 코드 참가, 두 참가자 상태 수신을 확인했다. 게임 데이터는 Relay를 경유한다.
- 이 검사는 같은 PC에서 수행했다. 서로 다른 인터넷 회선, 네트워크 차단, 서비스 장애, 지연 시간은 검증하지 않았다.

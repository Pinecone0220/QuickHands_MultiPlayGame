# BAS 단발 볼트액션 / ADS·지향사격 — 2026-10-22

BAS(무기3)를 퀵핸즈 선택/준비 연습/메인 무기 정보/HUD/킬로그에 추가했다. 기존 무기 ID는 유지한다. 초안은 첫 준비4행동×4자리, 재장전3행동×4자리다. 실제 서버 헤드샷은100피해/목숨2개 차감, 나머지 부위는0피해/명중 피드백 없음이다. 다른 미니게임의 공유 한 발 리볼버는 기존 규칙을 유지한다.

모든 ADS의 무작위 탄퍼짐은0이며 현재 흔들리는 시선으로 발사한다. 추적·명중 보정·가림 무시는 없다. BAS는3배율 스코프/9도 수평 흔들림/극단적인35~70도 지향 편차다. 리볼버 지향10도, 소드오프 지향12도/유효 거리6m다. 소드오프 ADS는37발이 같은 방향으로 나가며 한 번의75+번호 이웃25 판정을 유지한다. 지향 편차가 총구 위치나 총기 렌더를 무작위로 이동시키지 않는다.

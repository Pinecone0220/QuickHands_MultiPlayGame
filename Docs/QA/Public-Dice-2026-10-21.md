# 무승부 용어·머리 위 공개 주사위 검증

Unity6000.3.18f1 / NGO2.13.3 / 프로토콜43 유지. 게임 UI 소스/스타일에서 동점·동률 문구가 남지 않았음을 확인했다.

Windows 개발 빌드 성공. 실행본 화면 검사20개와 독립 호스트38·원격29·세 번째 참가자26개, 총113개를 통과했다.

- 6좌석 장면에서 타인 머리 위 팔면체의 실제 회전, 서버 확정 눈, 여러 좌석의 독립 렌더, 일반 창 뒤 표시, 결과3초 유지/종료 후 숨김, 자리 이탈 후 렌더 카메라 꺼짐을 확인했다.
- 각 원격 화면에서 다른 참가자의 주사위 이미지와 확정 숫자를 기존 공개 Dice 상태와 비교했다. 공개 주사위는 입력을 가로채지 않으며 채팅 중SPACE는 여전히 확정으로 사용하지 않는다.
- 뭐였더라?의 우승자 전용 주사위/사격자·한 발/목숨 보존과 이후 퀵핸즈 동시 사망·목숨0 주사위 참여도 통과했다.
- 전용 주사위 카메라는 낮은 해상도와 독립 위치/시야를 사용한다. 그림자/후처리/색·깊이 텍스처 복사를 끄고 화면에 보이는 좌석만 활성화한다. 생성 메시·재질·렌더 텍스처는 기존 컴포넌트 수명에 맞춰 정리한다.

제작 소스와 격리 QA 소스의 관련 파일 해시가 일치한다. 미리보기: `Docs/Previews/Public-Dice-Rolling.png`, `Docs/Previews/Public-Dice-Results.png`. 전용 서버/인터넷 지연·손실 실기동은 이번 범위에 포함하지 않았다.

재현은 격리 QA 프로젝트의 Tools/UnityQA/DiceRuntimeQA.cs로 한다. 화면 검사는 `--dice-qa overhead --dice-dir <새 폴더>`, 원격 검사는 각 실행본에 `--dice-qa host/client/observer --dice-memory-winner --dice-dir <공유 새 폴더>`를 전달한다. 제품Assets에 QA 도구를 추가하지 않는다.

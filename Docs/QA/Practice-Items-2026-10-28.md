# 로비 아이템 연습 검증

- Unity 6000.3.18f1 / NGO 2.13.3 / Windows Development 빌드 성공. 연습 요청과 규칙 변경으로 프로토콜61.
- 로비에서 준비한 참가자에게 선택한 아이템만 표시하고 서버가 해당 좌석의 선택·준비 상태와 연습 세션을 검증한다. 준비 취소 후의 오래된 요청은 거절한다.
- 연습 아이템은 소모나 쿨타임 없이 반복할 수 있으며 본 경기의 체력·목숨·보유량을 변경하지 않는다. 앰플은 연습 HP가100이어도 효과를 표시하고, 총알의 추가 발사는 연습이 무제한 사격이므로 선택 표시로 시험한다.
- 테이저·먹물은 준비한 다른 참가자에게만 판정하며 감전/시야 방해를 표시한다. 패딩은 감전 면역을 제공한다. 준비 취소와 경기 시작 시 해당 연습 상태를 정리한다.

## 결과

- `Tools/Test-PracticeItems.ps1`: 24개 통과. 선택/준비 검증, 재사용, 패딩 면역, 테이저 즉시 적중과 감전 만료, 먹물 투척, 무피해·무소모, 준비 취소, 경기 시작 시 초기화 확인.
- `Tools/UnityQA/PracticeItemsRuntimeQA.cs`: 호스트15개·원격 참가자11개·관전자4개 통과. 아이템 UI, 호스트/원격 효과, 제3자 전기 효과, 먹물 화면 효과, 오래된 세션 요청 거절 확인.
- 직접 호스트 접속 재검증: 호스트24개·원격18개 통과. 같은 PC의 별도 실행 파일로 생성·접속·재접속 및 준비 유지 확인. 실제 별도 PC의 LAN 환경은 포함하지 않는다.
- 기존 테이저82개·패딩46개·AI 장비171개 및 패치노트14개 검사 통과. 오늘 날짜의 변경 사항을 패치노트에 추가했다.

# 리볼버 공통 지향 탄퍼짐·저격소총 이름 검증

2026-10-22 / Unity6000.3.18f1 / NGO2.13.3 / Transport2.7.3 / 프로토콜50.

리볼버 지향사격을 기존 BAS와 동일한35~70도 중심 제외 분포로 변경했다. 무작위 방위각과 `70*sqrt(0.25+0.75*u)` 반경을 사용하며, 준비 연습과 본 경기에서 DuelGunplay.PrecisionSpreadRadius를 공유한다. 정조준 퍼짐0/기존 ADS 흔들림, 지향 화면 무흔들림, 실제 서버 투사체/피해/장전/탄 소모는 유지한다.

공개 이름은 WeaponRules.Name에서 BAS→저격소총으로 변경했다. 선택/정보/툴팁과 피해 표시 등 이름을 사용하는 화면에 함께 적용한다. 내부 enum값3과 BAS 식별자, 모델·오디오 리소스 키는 유지한다. 탄도 의미 변경으로 프로토콜50을 사용하며 메시지 필드는 변경하지 않았다.

Windows 빌드 성공. 현재 AdsRulesRuntimeQA로 모델118개·실제 호스트4개/원격 클라이언트8개를 통과했다. 모델에서 기존 박제 문구41개 회귀 검사도 실행했다.

- 반경 표본0~1의21개 지점에서 리볼버/저격소총 분포가 완전히 같고35~70 범위임을 확인했다. 같은 표본에서 두 무기의 ADS 무작위 퍼짐은0이다.
- 고정 서버 난수로 두 무기의 본 경기/준비 연습 실제 Fire가 같은 반경을 만들고 지향 흔들림을 더하지 않는지 확인했다. ADS Fire는 각 무기의 기존 Sway 방향을 정확히 따랐다.
- 원격 클라이언트의 준비 연습과 본 경기에서 리볼버 지향 발사 후 서버/소유자 스냅샷의 실제 FiredYaw/Pitch가35~70도 분포에 있고 탄을 정상 소비했다.
- 소드오프 ADS 차단/6도 산탄·20m·AI 반복 사격 등 이전 규칙도 함께 통과했다. 공개 이름은 저격소총이며 소스에 사용자 표시용 BAS 문자열이 남지 않았는지 확인했다.

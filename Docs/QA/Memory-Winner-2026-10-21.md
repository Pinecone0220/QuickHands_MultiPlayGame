# 뭐였더라?의 우승자 판정 검증

Unity6000.3.18f1 / NGO2.13.3 / 프로토콜43 유지.

하위 오입력/주사위 동점을 따로 순위 매기지 않고 최종1등을 결정하는 주사위만 사용한다. 남은 전원 정답은 다음 라운드, 다른 기록은 최다 오류 참가자들 미니 탈락, 남은 전원이 같은 양수 오류이면 우승자 전용 주사위다. 기존 라운드/길이는 유지한다.

- Windows 개발 빌드 성공, 규칙133개 통과. 기존 주사위/전원 실패/초읽기 시간 초과 회귀를 포함한다.
- 6명에서 한 명씩 탈락해2명이 남았을 때5라운드·7방향이 유지되고, 둘 다 정답 후6라운드·8방향에서 같은 오입력일 때만 주사위를 굴리는지 확인했다.
- 하위 오입력 동점은 주사위 없이 탈락하며 남은 참가자는 기존 라운드를 계속한다. 첫 라운드 전원 같은 오입력도 주사위로 판정한다. 미입력 동점도 검사했다.
- 주사위8·2·2는1등 확정 후 종료한다. 8·8·2는 최고 눈 두 명만 재굴림하며, 이전 하위 눈은 재굴림 대상이 되거나 상위 그룹을 추월하지 않는다.
- 독립 Windows 호스트35·원격26·세 번째 참가자23개, 합계84개 통과. 실제 SPACE→소유자RPC로 첫 라운드의 전원 오입력 주사위를 확정하고, 하위 눈 동점 재굴림 생략/동일 사격자/한 발 지급/목숨 보존/결과의1등·탈락 표시를 확인했다. 이후 퀵핸즈의 기존 동시 사망·목숨0 주사위 참여도 통과했다.

총217개. 제작 소스와 격리 QA 소스의 관련 파일 해시가 일치한다. 전용 서버/실제 인터넷 지연·손실 실기동은 이번 범위에 포함하지 않았다.

재현 도구: `Tools/UnityQA/DiceRuntimeQA.cs`. 격리 프로젝트의 실행본에서 `--dice-qa model --dice-dir <새 결과 폴더>`를 실행한다. 원격 검사는 각 실행본에 `--dice-qa host/client/observer --dice-memory-winner --dice-dir <공유 새 결과 폴더>`를 전달한다. 기록 생성용 조작은 QA 환경에만 있으며 제품RPC에 추가하지 않았다.
